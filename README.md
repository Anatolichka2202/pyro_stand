# Pyro-stand

Операторское приложение регистрации пироканалов по циклограмме и в свободном
режиме. Получает ПЗ от Debug-модуля КАСУПП; самостоятельно ПЗ на БЦВМ не передаёт.

## Сборка

Нужны C++20, CMake 3.16+, Ninja и Qt 6 с модулями Core, Widgets, Network,
SerialPort, Concurrent, Test. Проверенная конфигурация Windows: Qt 6.8.0,
MinGW GCC 13.1. Используйте Qt и компилятор из одного комплекта.

Добавьте инструменты Qt, компилятор, CMake и Ninja в PATH. При необходимости
задайте CMAKE_PREFIX_PATH на каталог комплекта Qt.

```sh
cmake -S . -B ../build/pyro_stand -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build ../build/pyro_stand
ctest --test-dir ../build/pyro_stand --output-on-failure
```

В Windows можно вызвать `build.bat`, в Linux — `bash build.sh`.
Сборка создаётся вне каталога исходников. Для запуска Windows EXE на другом
компьютере выполните `windeployqt --release <путь-к-pyro_stand.exe>`.

## Запуск

```sh
../build/pyro_stand/pyro_stand --tester udp --board-ip 192.168.17.144 --first-stage-yps 8 --second-stage-yps 7 --kp-yps 8
```

В Windows исполняемый файл имеет расширение `.exe`. Подключение и назначения
можно изменить кнопкой «Подключение». Номера ЯПС в примере человеческие, от 1;
они подходят только указанной разводке. Остальные параметры: `pyro_stand --help`.

Для плана запустите КАСУПП с Debug-модулем и тем же именем локального сокета:
`kasupp-debug-events-v1`. Загрузку ПЗ выполняйте через КАСУПП.
Без КАСУПП доступны «Живые каналы» и «Свободная запись».
Таймлайн выбирается мышью или стрелками/Home/End; слева можно оставить входы
выбранного события. В итогах отдельно показаны отклонения и незарегистрированные
входы. Ручное завершение сохраняет неполный результат и его причину.

Новая плата передаёт аппаратные микросекундные отметки; старая — байт маски за
миллисекунду через COM 115200 8N1. Разные приборы имеют независимые счётчики.
Автоматическое сведение их часов пока не реализовано. После потери связи
неполный прогон не доказывает отказ исполнительной цепи.

## Редактор циклограмм (первая часть E5)

В меню «Ещё» доступны «Редактор циклограмм…» и «Открыть файл в редакторе…».
При первом запуске укажите исполняемый файл редактора (Windows: `cyclogram-editor.exe`
из виртуального окружения разработчика или будущей portable-сборки). Путь
запоминается в настройках Pyro-stand. При наличии редактора рядом с Pyro-stand
он обнаруживается автоматически. Для выбранного `.txt`/проекта запускается
`cyclogram-editor --open <путь>`; аргументы передаются без shell.

**Важно:** это только запуск внешнего приложения. Выбор файла в редакторе
не загружает его на БЦВМ и не подменяет штатное ПЗ, полученное через КАСУПП.
Локальные измерения и переоценка карты требуют отдельного этапа E5.


## Локальная циклограмма: безопасный предварительный режим E5

```sh
pyro_stand --tester udp --board-ip 127.0.0.1 --board-port 5000 --local-cyclogram "C:/ПЗ/тест.txt"
```

При `--local-cyclogram` Pyro-stand не подключается к Debug КАСУПП, не создаёт
`upload_id` и не присваивает локальному плану состояние `CONFIRMED`.
Открытый файл отображается в таблице и на временной шкале. Физические кадры
пиротестера архивируются, в отчёте стоит `plan_origin=local_file_unconfirmed`.
Запуск с одновременным явным `--debug-socket` отклоняется.
Локальная регистрация завершается вручную либо при достижении порога 16 МиБ
JSONL; последняя порция сохраняется целиком, поэтому размер может превысить
порог на её размер. Расписание неподтверждённого ПЗ не завершает запись.
Потеря новой платы завершает запись неполной; потеря OLD COM отмечается как
разрыв связи и сама по себе не завершает запись.
Ошибка записи архива прерывает локальный сбор и запрещает выдавать полный отчёт.
При пересоздании дополнительного прибора сверяется SHA-256 локального ПЗ.
Если файл изменился, дополнительный прибор не подключается: нужен новый сеанс
с выбранной версией файла.

**Ограничение:** данный шаг E5 обеспечивает только план и регистрацию сырых данных.
Он **не** выдаёт «измерено» или «в допуске» по локальному плану. Достоверная
оценка локальных испытаний, ожидаемые проверки проекта редактора и переоценка
по версиям карты будут реализованы отдельно. Редактор и Pyro-stand не отправляют
команд исполнения циклограммы БЦВМ.
